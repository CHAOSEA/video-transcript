这份素材可供后续小红书 Skill、人工编辑或图文发布流程复用。当前只准备文案与图片，**没有自动登录、上传或发布**。

## 图文正文草稿

最近把一个开源 CLI 做到了可以真实跑通的阶段：输入在线视频链接，先尝试获取人工字幕或自动字幕；在平台允许访问、也没有可用字幕时，再下载媒体并在本机用 CPU 做语音识别。

结果会生成两份文件：

- `transcript.md`：带时间轴、方便阅读的逐字稿
- `evidence.json`：保留原始分段、来源、模型和运行信息，便于回看结果是怎么来的

目前的实测是按具体样本记录的：YouTube 的人工和自动字幕路径通过；Bilibili 的无字幕音轨转录通过；小红书有一条公开视频完成 HTTPS MP4 到本地 ASR 的完整流程。抖音在线流程仍被平台访问验证阻断，Bilibili 和小红书的字幕成功路径也还没有实测通过。

所以这不是“四个平台全部畅通”的承诺。平台可能要求验证、没有字幕或无法提供可访问媒体；遇到这些情况，工具会报告限制，不读取浏览器 Cookie，也不绕过平台检查。

另一个我很看重的点是：原始识别分段会保存在证据文件里，Markdown 负责时间轴展示，不会用润色后的文字覆盖原始结果。目前还没有人工校订稿 CER 基准，因此也不宣称某个模型准确率最高。
